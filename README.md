# 飞花 · 诗词对弈

在浏览器里玩飞花令：给一个令字，与对手轮流吟出含这个字的诗句。

- **飞花令**：经典规则与位置飞花，四档对手水平，可限时；也能和同桌在一台设备上轮流对战
- **上下句**：看上句选下句（偶尔反过来），十题一轮
- **诗句填字**：名句缺一字，四选一
- **诗库**：按题目、作者、字句检索，竖排阅读、收藏
- **我的**：令字纪录、生疏句、收藏、吟过的诗句

所有记录保存在本机浏览器的 localStorage 中。

## 数据

诗词文本整理自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT），经繁简转换：

- `data/core.json`：唐诗三百首、宋词三百首、千家诗、诗经、南唐二主词、曹操诗集，以及补录的名篇，约 1,260 首
- `data/ext.json`：李白、杜甫、苏轼、辛弃疾等数十位诗人词人的全集，约 2.5 万首，用于核对玩家诗句，按需加载
